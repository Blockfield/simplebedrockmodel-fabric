# Blockfield/simplebedrockmodel-fabric bf4

## Кратко

Первый документированный релиз форка SimpleBedrockModel (библиотека рендера Bedrock-моделей) для Blockfield: перенос на Fabric 1.21.1 (апстрим синхронизирован до версии 2.5.1), две правки рендера брони и заметная доработка системы частиц/анимаций (Molang-подобный движок на ASM с интерпретатором как фолбэком).

## Для игроков

Исправления: рука в первом лице снова корректно показывает броню — `PlayerRendererMixin` не рассылал `RenderArmEvent`, из-за чего рендерер брони, получаемый через лямбду `fabric-rendering-v1`, не подключался; отдельно исправлено, что взрослые мобы/игроки могли получать поправку модели, предназначенную для детской версии («young» теперь берётся из контекста модели, а не наследуется по умолчанию).
Остальные изменения промежутка — это сама библиотека рендера (движок частиц и анимаций, поддержка Bedrock-моделей брони/сущностей) и её примеры (в т. ч. пример рендерера для `DeagleItem`, совместимость примеров брони с первым лицом и с Epic Fight). Библиотека сама по себе не добавляет контента — её эффект для игрока проявляется через моды, которые её используют для моделей оружия/брони; какие именно моды подключают эту версию, из коммитов не видно.

## Технические изменения

Порт SimpleBedrockModel на Fabric 1.21.1 (апстрим синхронизирован до 2.5.1), сборка на temurin-21 через mise, `gradlew` сделан исполняемым; CI — workflow сборки на Java 21 с сохранением артефактов, лимит 30 минут, обновлены actions до Node 24. Система частиц и анимаций переработана: единая точка рендера частиц от первого лица, рефакторинг структуры компонентов, событийные компоненты частиц с тестовыми частицами, отладочная команда частиц, разбор частичных компонентов, исправление сетевой обработки одного из пакетов, анимация не продвигается при паузе игры. Добавлен Molang-подобный движок выражений (обновление версии MAE): компиляция в байткод через ASM с тестами/бенчмарками и исправлением генерации байткода, с откатом на интерпретатор при отказе скомпилированного режима; сделана попытка портировать алгоритм отсечения (culling) из tlm и хук в ванильный рендер частиц для симуляции Snowstorm-частиц от первого лица.

## Обновлённые компоненты

- SimpleBedrockModel: апстрим синхронизирован до версии 2.5.1 (коммит «sync 2.5.1», далее перенесён на Fabric 1.21.1).
- Молang-движок (MAE): версия обновлена в рамках промежутка, но конкретный номер в заголовках коммитов не назван.
  Прочих внешних зависимостей в коммитах промежутка не видно.

## Совместимость и необходимые действия

Большая часть работы — клиентский рендер (миксины брони, частицы, анимации), но один коммит явно правит обработку сетевого пакета — значит, задействован и сервер. По коммитам нельзя точно разграничить, какая часть логики требует совпадения версий на обеих сторонах; пин пака безопаснее обновить одновременно на клиенте и на сервере.

## Известные проблемы

В самих коммитах промежутка авторы отмечают часть работы как незавершённую («добавлен разбор частичных компонентов частиц, реализация ещё предстоит», «попытка исправить проблемы частиц от первого лица, требует доработки») — подтверждения, что это доведено до конца в пределах этого же промежутка, в коммитах нет.

## Источники и ограничения полноты

- Коммиты null..bf4: список ограничен 40 записями (выборка); включает CI-настройку релиза, порт на Fabric 1.21.1, правки рендера брони и работу над движком частиц/анимаций и Molang-подобным интерпретатором.
- Часть заголовков коммитов на китайском языке переведена по смыслу; при неоднозначности перевод осторожный (например, «待做»/«待改» переданы как «ещё предстоит»/«требует доработки»).
- Диффстат по промежутку не собран (доступны только заголовки коммитов).

Неполнота: список коммитов мог быть обрезан лимитом выборки (40), полный diff и то, какие моды используют эту библиотеку в паке — по репозиторию.
